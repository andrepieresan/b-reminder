# Contributing

Contributions are welcome through issues and pull requests.

Before opening a pull request:

1. Keep changes focused and avoid unrelated refactors.
2. Run `go test ./...`, `go vet ./...`, and `go build ./...`.
3. Do not include credentials, real recipient identifiers, spreadsheet IDs, or
   private infrastructure details.
4. Update the documentation when configuration or behavior changes.

By contributing, you agree that your contribution is licensed under the MIT
License used by this project.
